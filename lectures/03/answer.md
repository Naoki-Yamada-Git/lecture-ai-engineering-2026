## 宿題

### やったこと
`app/agent.py` の `INSTRUCTIONS` にある「回答の最後に、関係する回（第N回）を示す。」という指示を「回答の最後に、学習内容を確認する問題を1問出す。」に変更した。

変更前後で「LoRAとQLoRAの違いは？」という同じ質問を `--trace` 付きで実行し、回答内容とツールの呼び出し方を比較した。

### 結果

| 比較項目 | 変更前 | 変更後 |
|---|---|---|
| 回答末尾 | 関係する回：第2回 | 学習確認問題を1問出力 |
| 呼び出されたツール | search_glossary | search_glossary |
| ツール呼び出し回数 | 2回 | 2回 |
| ツールの引数 | LoRA、QLoRA | LoRA、QLoRA |
| LLM呼び出し回数（requests） | 2回 | 2回 |
| 出力トークン数 | 194 | 232 |

変更前後ともに、以下の2つのツール呼び出しが行われた。

```text
[tool call] search_glossary({'query': 'LoRA'})
[tool call] search_glossary({'query': 'QLoRA'})
```

変更前は回答の最後に「関係する回：第2回」と表示されたが、変更後はQLoRAのメリットに関する学習確認問題が追加された。一方、ツールの呼び出し回数・引数・LLMの呼び出し回数には変化がなかった。

### 気づき・疑問
指示文を1行変更するだけで、回答の形式を変えられることが確認できた。一方、検索ツールの呼び出し方は変わらなかったため、回答形式の指示とツール使用の指示は異なる役割を持つと考えられる。また、確認問題の追加に伴い出力トークン数が増加した。
