## 宿題

- 取り組んだレベル：発展
- やったこと：`app/ask.py` を改修し、API 呼び出しの応答時間と入力・出力トークン数を表示するようにした。`AIE_MODEL` でモデルを切り替え、次の2つの質問を比較する。
	- `LoRAとは何ですか？`
	- `AIE2026の講座の宿題にある「3レベル」とは何ですか？`
	- 比較モデル：`gemini-3.5-flash-lite`、`gemini-3.5-flash`
- 結果：実測結果は次の通りだった。応答時間は API 呼び出しにかかった時間で、実行ごとに変動する。

	| モデル | 質問 | 応答時間 | 入力 | 出力 |
	|---|---|---:|---:|---:|
	| `gemini-3.5-flash-lite` | LoRAとは何ですか？ | 3186 ms | 7 | 651 |
	| `gemini-3.5-flash-lite` | 講座の宿題にある「3レベル」とは？ | 3086 ms | 21 | 605 |
	| `gemini-3.5-flash` | LoRAとは何ですか？ | 9789 ms | 7 | 718 |

	同じ LoRA の質問では、今回の実行に限ると `gemini-3.5-flash-lite` の方が速く、出力トークン数も少なかった。モデルごとの比較をさらに正確にするには、同じ質問を複数回実行して平均値を取る必要がある。追加の比較には次のコマンドを使える。

	```bash
	AIE_MODEL=gemini-3.5-flash-lite uv run python -m app.ask "LoRAとは何ですか？"
	AIE_MODEL=gemini-3.5-flash uv run python -m app.ask "LoRAとは何ですか？"
	AIE_MODEL=gemini-3.5-flash-lite uv run python -m app.ask "AIE2026の講座の宿題にある「3レベル」とは何ですか？"
	AIE_MODEL=gemini-3.5-flash uv run python -m app.ask "AIE2026の講座の宿題にある「3レベル」とは何ですか？"
	```
- 気づき・疑問：同じ質問でも応答時間や出力トークン数は毎回変わり得る。質問が長いほど入力トークン数が増え、回答が詳しいほど出力トークン数も増える。短時間に大量の比較を行うと無料枠のレート制限（429）に達する可能性があるため、実行間隔を空け、エラーが出た場合は待ってから再実行する必要がある。
